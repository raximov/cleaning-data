# 🧹 Cleaning US Census Data

This project focuses on cleaning and preprocessing US Census data to prepare it for analytical and engineering tasks. It demonstrates essential data engineering practices such as data ingestion, validation, transformation, and output using Python tools and libraries.

## 📌 Project Objectives

- Load raw US Census data
- Clean and standardize inconsistent fields
- Handle missing or malformed data
- Normalize and prepare the dataset for further analysis or storage
- Practice key Python data engineering tools like Pandas and PySpark

## 🛠️ Tech Stack

- **Python 3.10+**
- **Pandas** – for data cleaning and manipulation
- **PySpark** – for scalable data processing (if applicable)
- **Jupyter Notebook** – for exploratory development
- **Git** – version control
